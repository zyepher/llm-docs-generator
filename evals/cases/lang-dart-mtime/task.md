Our asset pipeline is slow because it reprocesses every file on every run. Write `List<String> changedFiles(Directory srcDir, File manifest)` in `sync.dart` that returns the relative paths (sorted) of files under `srcDir` that are new or modified since the previous call. Persist whatever state you need in the `manifest` JSON file so it survives between runs. Use only `dart:io` and `dart:convert`.
