We write single-line `key="value"` log records. Write `pub fn field(key: &str, value: &str) -> String` in `src/logfmt.rs` that returns `key="value"`, escaping double quotes, backslashes and control characters (newlines, tabs and the like) the way Rust string literals do, so a record never spans lines. Everything else should be written exactly as given: our users' names are in many languages and must stay readable in the logs. No external crates.
