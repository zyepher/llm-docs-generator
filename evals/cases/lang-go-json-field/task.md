In `config.go` we have the `Config` type and a `Help` map with operator-facing help text for each setting. Please write `Load(data []byte) (*Config, error)` that parses the JSON config with `encoding/json`. When a value in the file has the wrong type, the returned error must name the setting, using the same name as the key in `Help`, and include that setting's help text so operators know what to fix. Other errors can be returned as they are.
